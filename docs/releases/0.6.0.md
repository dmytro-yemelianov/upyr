# Upyr 0.6.0 preview

Upyr fixes English ↔ Ukrainian text typed on the wrong keyboard layout, locally
on your device.

- Correction can happen during a clearly wrong-layout word (`сщте` → `cont`,
  `dbgh` → `випр`) and use short-word context (`nj vb` → `то ми`, `Ш have` → `I have`).
- The correction engine reuses bounded indexes and buffers. Correctness,
  allocations and memory limits have reproducible regression checks.
- Complete pixel settings open from the menu bar, with seven searchable pages.
  Ukrainian is the default interface language; English is available in General.
- Safer macOS correction during continuous typing, better clipboard restoration,
  and automatic pause in remote-desktop / virtual-machine apps.
- A compact website and README, plus a commit-bound engineering self-audit with
  coverage, dependency findings, code checks and performance measurements.

Automatic correction remains opt-in. Existing settings are preserved on upgrade.

| Platform | Package |
| --- | --- |
| macOS 11+, Apple Silicon + Intel | `upyr-macos-universal-0.6.0.dmg` or `.zip` |
| Windows x64 | `upyr-windows-x86_64-0.6.0-setup.exe` or portable `.zip` |
| Linux X11 x64 | `.deb` or portable `.tar.gz` |

On macOS, quit Upyr and replace `/Applications/Upyr.app`; open it again. Keep
Accessibility access enabled. On Windows use the installer or replace the
portable folder. On Linux install the DEB or replace the portable directory.
The package-manager / crates.io channels are not updated by this preview.

macOS is the primary desktop target; Windows and Linux/X11 are previews. Native
Wayland global input is unsupported. The macOS bundle is ad-hoc signed and not
notarized; Windows preview packages may be unsigned.

See `SHA256SUMS.txt` for package integrity, `self-audit.tar.gz` for the engineering
evidence and `release-validation-0.6.0.json` for downloaded-package verification.
The audit is a self-assessment, not independent certification; its report lists
warnings, measured scope and unmeasured areas.
